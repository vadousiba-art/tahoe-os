# Kiri Studio — Tahoe Edition

A desktop transformation for **Ubuntu MATE** that recreates the look and feel of macOS Tahoe 26 (menu bar, Liquid Glass-style dock, Control Center, Notification Center, Spotlight, Finder-style file manager, System Settings), aimed at the 2014 Intel MacBook Air with 4 GB RAM. Every change can be undone.

**Status: Phase 1, planning.** Nothing installable yet.

1. Run the read-only inspector on your machine: `bash tools/kiri-inspect.sh`
2. Read the plan: [docs/01-compatibility-and-plan.md](docs/01-compatibility-and-plan.md)
3. Paste the report back and approve the plan; then the build starts.

Not affiliated with Apple. Apple's wallpapers, icons and fonts are not bundled; you can import assets you are authorized to use.
